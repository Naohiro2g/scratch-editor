# mc-remote拡張機能カードの画像

拡張機能選択画面ではPNGを使用する。元SVGの文字はテキストとして残っているため、
閲覧端末に指定フォントがないと文字の形が変わる。PNGは指定フォントで描画済みなので、
閲覧端末へのフォントのインストールは不要。

| 用途 | 配信する画像 | ピクセル寸法 | 通常の表示サイズ |
| --- | --- | --- | --- |
| カード上側の主画像 | `mcremote.png` | 1200×744 | 約296×183 CSS px |
| ミニアイコン | `mcremote-small.png` | 320×320 | 40×40 CSS px |

印刷と高密度画面を考慮し、主画像は通常の表示幅の約4倍、ミニアイコンは約8倍で保存している。
PNGの解像度情報は300 dpi。
表示サイズは既存のCSSで決まり、ミニアイコンの透明背景も保持する。

編集用の元画像は[mcremote.svg](mcremote.svg)と[mcremote-small.svg](mcremote-small.svg)。
PNGはlibrsvgとCairoで変換し、SVGの指定フォント`karabinE.`と`URW Classico`が
存在する環境で描画した。再変換時も指定フォントが使われていることと、文字・影・透明背景を確認する。
フォントデータは画像に同梱しない。
